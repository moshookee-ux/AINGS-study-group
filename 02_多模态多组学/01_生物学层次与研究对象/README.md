# 01 生物学层次与研究对象

[AINGS](../../README.md) · [多模态多组学](../README.md)

多模态多组学研究从一个问题出发：同一个生物系统，在不同测量方式下呈现的变化怎样联系起来？理解这个问题，需要先分清三个层次：**生物对象是什么、实验实际测到了什么、模型收到的数字代表什么**。本章建立生物对象，[第 2 章](../02_测量技术与多组学数据结构/README.md)解释测量，[第 3 章](../03_质量控制_预处理与数据表示/README.md)把测量连接到可分析的数据。
