# 方法与模型基础

这个模块关注的是基础方法脉络，而不是某一版项目代码。

重点问题是：

- 数据分析方法为什么会分出不同路线
- 病原识别和耐药检测为什么不应该直接共用同一套输入和输出
- 一个模型输出为什么必须配套评估、校准和拒识
