## 新增与小修正

新增统一首页、路线导读、学习依赖 DAG、分析流程图、共用活动流程、两条路线的阶段成果、实践选题、共建说明和三类专题模板。

知识库第 7.5 节的 R13 链接在原稿中被截断，已依据同一原稿第 13.4 节的完整 DOI 补齐；该 DOI 的括号使用 URL 编码以稳定 Markdown 解析。原始快照保持不变。

新增 DAG 的箭头表示学习依赖或工作流程。知识库第 9.7 节原有的主动学习图包含反馈循环，继续作为闭环流程示意保留，与新增无环依赖图分别理解。

当前版本的主题安排、时间与岗位均属于组织建议。实际举办的分享与成员认领情况，后续记录在 notes 和项目说明中。
