# AINGS学习小组文件夹架构

## 架构原则

这个目录按“知识问题域”组织，而不是按“文件格式”或“某个项目阶段”组织。

换句话说，我们更关心：

- 一个新同学要先理解什么
- 一个问题属于临床、实验、生信、统计还是模型层
- 后续资料该归到哪一类而不至于越积越乱

## 模块边界

### 01_检验医学与临床微生物学

关注：

- 样本怎么采
- 样本怎么处理
- 药敏结果怎么读
- 不同样本为什么解释不同
- 病原体与宿主反应的临床背景

### 02_生物信息学基础

关注：

- 测序方式和数据形态
- 物种鉴定的基本证据链
- “是不是新物种”该怎样严肃判断
- ARG、毒力和移动遗传元件分别是什么

### 03_数据与统计基础

关注：

- mNGS 数据为什么难
- 丰度与归一化问题
- 污染、批次效应、宿主背景
- 标签质量和训练/测试边界

### 04_方法与模型基础

关注：

- 从传统比对到 k-mer、sketch、embedding 的方法脉络
- 病原识别与耐药检测为什么不是同一个任务
- 模型输出为什么必须配合评估、校准和拒识

### 05_文献精读与教学组织

关注：

- 读书会如何组织
- 后续如何把文献、代码和会议学习材料接起来

## 管理建议

1. 新增知识笔记时，优先放进最贴切的问题域。
2. 如果某个文件同时涉及多个主题，优先放主模块，并在其他模块 `README.md` 中补链接。
3. 不要把临时会议结论直接混进基础知识笔记。
4. 基础知识笔记尽量写成“面向新成员”的格式，而不是默认读者已经知道项目上下文。
5. 参考文献请优先登记到 `reference-index.md`，再决定是否拆进各模块单独的阅读页。
