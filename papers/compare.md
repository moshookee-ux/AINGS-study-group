# 方法对照：先认清问题，再比较方法

[论文与方法](README.md) · [检验医学与病原生信](../01_检验医学与病原生信/README.md) · [多模态多组学](../02_多模态多组学/README.md)

遇到一个新方法，可以先问三个问题：它接收什么数据，借用了什么信息，最后输出什么？下面的对照表方便选阅读入口，也方便整理自己的实验方案。

## 序列分类：先比较参考信息与任务层级

| 方法 | 主要表示／检索对象 | 参考信息怎样进入 | 阅读时对齐的条件 |
| --- | --- | --- | --- |
| [Kraken 2](kraken2.md) | k-mer 的 minimizer 与紧凑哈希 | 带分类标签的序列索引 | 数据库范围、参数、分类层级 |
| [Centrifuge](centrifuge.md) | 参考序列与压缩索引 | 近缘序列压缩及 BWT／FM-index | 参考库大小、歧义匹配、丰度估计 |
| [Kaiju](kaiju.md) | 翻译后的蛋白片段 | 带分类标签的蛋白库 | 编码信息、参考距离、精确率与灵敏度 |
| [DeepMicrobes](deepmicrobes.md) | canonical 12-mer、LSTM 与注意力 | 带分类标签的训练序列 | 训练参考、序列长度、已知类别范围 |
| [BERTax](bertax.md) | 3-mer 与预训练表示 | 序列预训练及分层分类标签 | 分类层级、近缘／远缘留出设置 |

同一批 reads、相同分类层级和可比参考信息，是理解差异的起点。方法需要额外标签、参考库或预训练数据时，把这些资源也记进比较表。

### 任务变了，输出也会变

| 问题 | 相关论文 | 输出怎样使用 |
| --- | --- | --- |
| 这段序列属于哪类 ARG？ | [DeepARG](deeparg.md) | 读耐药类别与概率，再结合序列证据 |
| 样本的病原与耐药线索怎样汇总？ | [CZ ID](czid.md) | 对照 reads、contig、物种与基因结果 |
| 两个基因组有多相近？ | [FastANI](fastani.md) | 一起查看 ANI、匹配范围与基因组质量 |
| 哪些特征可能来自污染？ | [decontam](decontam.md) | 结合浓度、阴性对照、批次与阈值 |
| 丰度的变化是什么尺度？ | [组成型数据](compositionality.md) | 明确比例、比值、总量与零值处理 |

## 多组学：先画出数据的对应关系

[CITE-seq](cite-seq.md) 与 [TEA-seq](tea-seq.md) 帮助理解配对关系来自怎样的联合测量。进入算法前，先列出细胞、供体、特征与已测模态。

| 方法 | 主要阅读场景 | 组织信息的方式 | 输出与阅读重点 |
| --- | --- | --- | --- |
| [WNN](wnn.md) | 同一细胞有多个模态 | 逐细胞学习模态权重并组合邻域 | 加权图；观察不同细胞依赖什么信息 |
| [totalVI](totalvi.md) | RNA 与蛋白计数联合分析 | 共享潜变量与不同观测分布 | 表示、去噪与统计分析；读蛋白背景模型 |
| [MultiVI](multivi.md) | 配对与未配对的 RNA／ATAC | 分模态编码、对齐与生成 | 联合表示和补全；读各类细胞的观测项 |
| [GLUE](glue.md) | 非配对细胞与不同特征空间 | 特征引导图连接组学表示 | 细胞／特征表示；读先验图与解码关系 |
| [MOFA+](mofa.md) | 多视图、多组别中的变化解释 | 因子与特征载荷 | 共享／特有变化；读解释方差与高载荷特征 |
| [scVAEIT](scvaeit.md) | 模态或面板不齐的 mosaic 数据 | 缺失掩码与条件生成 | 补全和表示；读真实缺失与训练遮挡 |
| [scGPT](scgpt.md) | 预训练表示迁移到指定任务 | 基因／表达输入与 Transformer | 任务相关表示和预测；读适配方式与数据划分 |

这些是理解论文的入口。具体实验中的输入接口、支持的缺失模式与设置，还需要对照所使用的版本和任务。

## 给自己的比较留一张记录表

[scIB](scib.md) 把生物结构保留与批次去除同时纳入评价。沿着这个思路，可以给自己的方案留下这些记录：

| 要记录的内容 | 一个具体问题 |
| --- | --- |
| 研究对象 | 预测的是 read、基因、细胞，还是供体？ |
| 输入与可用信息 | 各方法拿到哪些模态、标签、参考库和先验？ |
| 数据划分 | 哪些供体、样本、基因组或细胞类型被留出？ |
| 输出 | 是标签、概率、图、潜在表示，还是对未测量的预测？ |
| 比较方法 | 简单基线能做到什么，额外模块增加了什么？ |
| 评价 | 同时查看哪些目标，是否按群体或缺失情况分开报告？ |
| 运行条件 | 使用的数据版本、参数、资源和结果在哪里？ |

可以把填好的表放进[项目与实践](../projects/README.md)，让感兴趣的伙伴接着复现、补充或提出新的比较。
