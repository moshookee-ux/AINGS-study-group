# reads、contig、ORF、SNP、MAG 是什么

[AINGS](../../README.md) · [检验医学与病原生信](../README.md) · [本模块目录](README.md)

## read

- 最原始的测序片段
- 优点：
  - 信息最直接
  - 易于快速筛查
- 局限：
  - 短
  - 上下文弱

## contig

- 多条 reads 组装后的更长连续片段
- 优点：
  - 上下文更强
  - 更适合基因或区域解释
- 局限：
  - 依赖组装质量

## ORF

- 开放阅读框
- 用来从核酸序列中预测可能编码蛋白的区域

## SNP

- 单核苷酸变异
- 更常见于 WGS 的菌株比较、系统发育和机制分析

## MAG

- metagenome-assembled genome
- 不是单条 contig，而是一组被归到一起、近似代表某个基因组的组装结果

## 为什么这些层级不能混着谈

因为“在 read 层面能做的事”和“在 contig / ORF / MAG 层面能做的事”不一样。

判断病原、判断新物种、判断耐药机制，常常依赖的是不同层级的信息。
