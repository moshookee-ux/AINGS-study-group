# 物种鉴定与新物种判断

[AINGS](../../README.md) · [检验医学与病原生信](../README.md) · [本模块目录](README.md)

## 物种鉴定的常规层次

从最弱到最强，常见证据大致可以是：

1. reads 命中到某个已知物种数据库
2. marker gene 或 16S 更接近某个已知类群
3. contig / MAG 的系统发育位置接近某一分支
4. 与已知参考基因组的 ANI / AAI / dDDH 达到物种阈值

## “可能是新物种”不等于“已经证明是新物种”

在生信分析里，更严谨的表达通常是：

- 未分类到已知物种
- 可能属于未知谱系
- 可能是 novel taxon candidate

而不是直接说“发现了新物种”。

## 判断一个样本里是否可能存在新物种的常见思路

### 第一步：排除低质量和污染

- 检查 reads 质量
- 检查宿主残留
- 检查环境污染和试剂污染
- 检查是否只是数据库缺失造成的假“未知”

### 第二步：尽量获得更稳定的组装或 bin

- 如果只有零散短 reads，很难严肃主张“新物种”
- 更理想的是有较好的 contig，甚至可用的 MAG

### 第三步：做已知数据库比较

- 16S / marker gene 比较
- GTDB / NCBI taxonomy 工具定位
- 与最近邻参考基因组做 ANI

常见经验阈值：

- ANI 大约低于 `95%~96%` 时，才开始考虑与已知物种存在明确距离

### 第四步：看系统发育位置

- 如果序列或 MAG 落在已知大类群中，但和任何已知物种都不够近，才更像潜在新类群

### 第五步：看是否有足够独立证据

- 完整度是否够
- 污染率是否可接受
- 是否有多个样本重复出现
- 是否有一致的生态或宿主背景

## 一个很重要的现实判断

在临床样本或复杂 mNGS 样本中，更多时候我们能做的是：

- 判断“它不像任何已知物种”
- 判断“它可能是一个未注释或数据库缺失的类群”

而不是直接完成正式新物种定义。

正式新物种命名通常还需要：

- 更高质量基因组
- 更系统的系统发育证据
- 常常还包括培养、表型和独立验证
